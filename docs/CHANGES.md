# Dokumentasi Perubahan dari Acode 1.13.5

Fork pribadi **Irham.s.a WebCode IDE**. Daftar versi, dari yang terbaru:

| Versi | Nama | Ringkasan | Dokumen |
|---|---|---|---|
| 0.4.0 | Preview | input file dan download di preview berjalan di dalam app | `versions/v0.4.0.md` |
| 0.3.0 | Pengembang | halaman About berisi data pengembang, logo di dalam app | `versions/v0.3.0.md` |
| 0.2.0 | Tema | 19 tema editor, 11 tema aplikasi, 6 tema terminal baru | `versions/v0.2.0.md` |
| 0.1.0 | Fondasi | rebrand, ikon, package name, fitur online dibuang | `versions/v0.1.0.md` |

Aturan penomoran: versi selalu naik. Setiap rilis wajib punya satu file `docs/versions/vX.Y.Z.md`, dan `config.xml` (`version`, `android-versionCode`) serta `package.json` (`version`) dinaikkan bersamaan.
