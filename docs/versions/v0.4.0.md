# v0.4.0 — "Preview" (input file dan download berjalan di dalam app)

Tanggal: 3 November 2026 · versionCode 4

## Masalah
Di Acode asli, halaman yang dibuka lewat preview dalam aplikasi tidak bisa memilih file (`<input type="file">`) dan tidak bisa mengunduh/ekspor file. Untuk mengujinya harus membuka Chrome.

## Penyebab (dari membaca kode `src/plugins/browser/.../Browser.java`)
1. **Download:** unduhan diserahkan ke `DownloadManager` milik sistem. `DownloadManager` hanya mengerti URL http/https biasa. Ia tidak bisa membaca `blob:` dan `data:`, padahal hampir semua "ekspor" di aplikasi web (CSV, JSON, gambar dari canvas, PDF) dibuat dengan `Blob` + `<a download>`. Untuk server lokal (localhost) juga tidak bisa diandalkan.
2. **Input file:** hanya tipe pertama dari atribut `accept` yang dipakai, dan langsung dijadikan MIME type. Nilai seperti `.json`, `.png`, atau `image/*,video/*` menghasilkan pemilih file yang salah atau kosong. Kegagalan juga tidak pernah ditampilkan, jadi terlihat "tidak terjadi apa-apa".

## Perbaikan
- **File baru `WebDownloads.java`** (didaftarkan di `plugin.xml`):
  - `http/https/localhost`: diunduh langsung oleh aplikasi (dengan cookie dan User-Agent halaman), bukan `DownloadManager`.
  - `data:`: didecode langsung.
  - `blob:`: skrip kecil disuntikkan ke setiap halaman. Skrip itu mencatat blob yang dibuat lewat `URL.createObjectURL` dan menangkap klik `<a download>`, termasuk anchor yang tidak dipasang ke DOM (`a.click()` dan `dispatchEvent`). Isinya dikirim ke Java per potongan 384 KB lewat jembatan `JavascriptInterface`, jadi file besar tidak memenuhi memori.
  - Sebelum disimpan, selalu muncul dialog konfirmasi **Simpan "nama" (ukuran) ke folder Download?** Ini penting karena halaman apa pun yang dibuka di preview (termasuk situs luar) bisa memanggil jembatan; tanpa konfirmasi, ia bisa menulis file tanpa sepengetahuan kamu.
  - File disimpan di folder **Download** (Android 10 ke atas lewat MediaStore, tanpa izin tambahan; di bawahnya lewat folder Download, dengan cadangan folder khusus aplikasi kalau izin penyimpanan tidak ada). Nama file dibersihkan dan diberi ekstensi dari MIME bila kosong. Nama yang sama otomatis diberi `(1)`, `(2)`.
- **Pemilih file** (`BrowserChromeClient.onShowFileChooser` di `Browser.java`):
  - `accept` dibaca penuh: banyak tipe, ekstensi (`.json`) diterjemahkan ke MIME, `multiple` didukung.
  - Kalau ada ekstensi, `application/octet-stream` dan `text/plain` ikut diizinkan, karena banyak file manager menandai file kode dengan tipe umum.
  - Kalau ada ekstensi yang tidak dikenal, pemilih dibuka tanpa filter (lebih baik tampil semua daripada kosong).
- **Setiap error muncul di dialog yang teksnya bisa dipilih, dengan tombol "Salin"** (jejak lengkap), juga ditulis ke logcat dengan tag `WebCodeDownloads`. Ini mencakup kegagalan membuka pemilih file, membaca file terpilih, mengunduh, dan menyimpan.
- Halaman uji siap pakai: `docs/test-preview-file-download.html`.

## Cara menguji di HP
1. Taruh `docs/test-preview-file-download.html` di folder proyek yang dibuka di app.
2. Jalankan preview **di dalam aplikasi** (bukan "buka di browser").
3. Bagian A (pilih file): tiap input harus membuka pemilih dan hasilnya tercatat di kotak Hasil.
4. Bagian B (download): tiap tombol memunculkan dialog Simpan. Setelah Simpan, muncul toast `Tersimpan: Download/...`, dan file ada di folder Download. Untuk tombol "Blob besar", ukuran file hasil harus tepat 3.145.728 byte.

## Diverifikasi
- Kode Java baru dan yang diubah **dikompilasi dengan `javac` terhadap `android.jar` API 33** tanpa error (dengan stub untuk kelas `R`).
- Skrip JavaScript yang disuntikkan diuji di happy-dom dengan jembatan palsu: blob 1.000.003 byte terkirim dalam 3 potongan dan tersusun ulang identik; blob kosong tidak error; link biasa tidak terganggu.
- `npx rspack --mode production` sukses. `npx vitest run`: 94 file / 919 test lulus. Catatan: satu test bawaan Acode (`nativeSearchProcessing`) mengompilasi Java dan butuh encoding UTF-8; di Windows biasanya sudah benar, di lingkungan ASCII jalankan dengan `JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8`.

## Belum diverifikasi
Perilaku di perangkat nyata (pemilih file bawaan HP, penyimpanan ke Download, dialog) belum bisa diuji di lingkungan pembuatan paket. Atribut `capture` (kamera langsung) belum ditangani; pemilih file biasa yang terbuka.

## Penting saat membangun ulang
Plugin `browser` disalin ke folder `plugins/` saat setup. Kalau kamu sudah pernah menjalankan `npm run setup` dengan versi sebelumnya, hapus folder `plugins` dan `platforms` lalu jalankan `npm run setup` lagi, supaya versi plugin yang baru ikut terpasang.
