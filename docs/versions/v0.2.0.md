# v0.2.0 — "Tema" (tema hacker, cyber, terminal)

Tanggal: 3 November 2026 · versionCode 2

## Tujuan
Memperkaya tema supaya tampilan tidak monoton, dengan gaya terminal, hacker, dan cyber seperti tema di VS Code.

## Tema editor baru (19) — `src/cm/themes/irhamThemes.js`
Terminal / hacker / cyber: **Hacker Green, Matrix, Cyber Neon, Cyberpunk Edge, Terminal Amber, Terminal Classic, Kali Dark, Ubuntu Terminal, Synthwave 84, Blood Moon**.
Gelap populer: **Night Owl, Rose Pine, Everforest Dark, Deep Ocean, Midnight Purple, OLED Black, High Contrast**.
Terang: **Paper Light**.

Satu fungsi pabrik `createIrhamTheme(config)` membangun tema dari palet warna, jadi menambah tema berikutnya cukup menambah satu objek di `irhamThemeConfigs`. Tema didaftarkan otomatis di `src/cm/themes/index.js`.

## Tema tampilan aplikasi baru (11) — `src/theme/preInstalled.js`
Hacker, Matrix, Cyber Neon, Cyberpunk Edge, Terminal Amber, Kali Dark, Ubuntu Terminal, Synthwave, Blood Moon, Midnight Purple, Paper. Setiap tema otomatis memilih tema editor dan tema terminal yang serasi (`preferredEditorTheme`, `preferredTerminalTheme`).

## Tema terminal baru (6) — `src/components/terminal/terminalThemeManager.js`
hackerGreen, matrix, cyberNeon, amber, kali, ubuntu.

## Cara memilih
Pengaturan → **Tema** → tab tema aplikasi atau tema editor.

## Test
`tests/irhamThemes.test.js`: id unik, semua warna lengkap dan valid, dan setiap tema bisa dibangun menjadi `EditorState`. Test bawaan Acode juga mengharuskan warna baris aktif transparan; tema baru disesuaikan.

## Diverifikasi
`npx rspack --mode production` sukses; `npx vitest run`: 93 file / 918 test lulus. Tampilan visual di perangkat belum dicek.
