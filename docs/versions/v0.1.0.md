# v0.1.0 — "Fondasi" (rebrand + mode offline)

Tanggal: 3 November 2026 · Basis: Acode 1.13.5 (MIT) · versionCode 1

## Tujuan
Mengubah Acode menjadi aplikasi pribadi yang murni offline untuk ngoding di HP.

## Perubahan

### Identitas
- Nama aplikasi: `Irham.s.a WebCode IDE` (`config.xml`, `package.json`).
- Package name: `com.irham.s.a.web.code.ide` (`config.xml`, `package.json`, `utils/config.js`, `utils/setup.js`).
- Ikon launcher baru berupa logo `</>` hijau-cyan di latar gelap: `res/android/drawable/ic_launcher_foreground.xml` dan `res/android/mipmap-*/ic_launcher*.webp`. Warna latar di `res/android/values/ic_launcher_background.xml` dan `utils/config.js`.
- Teks "Acode" di semua file bahasa `src/lang/*.json` diganti "WebCode IDE".
- Semua referensi yang bergantung pada package name disesuaikan agar build Android tidak rusak: import kelas `R` di `src/plugins/terminal/.../AlpineDocumentProvider.java` dan `src/plugins/browser/.../Menu.java`, aksi di `TerminalService.java`, authority dokumen di `src/utils/helpers.js` dan `src/lib/openFolder.js`, fallback di `terminalManager.js` dan `hooks/post-process.js`.

### Fitur online dibuang (`src/main.js`)
- Koneksi dan pengecekan pembelian Google Play (IAP) dihapus.
- Login akun Acode dan pengecekan status pro dihapus.
- Inisialisasi iklan (`adRewards`, `startAd`) dan pengambilan promosi (`fetchPromotions`) dihapus.
- Pengecekan update aplikasi ke GitHub dan dialog persetujuannya dihapus.
- Pengecekan update plugin dan pemuatan plugin (`loadPlugins`) dihapus.
- `config.HAS_PRO` selalu `true`, sehingga tidak ada fitur terkunci dan kode iklan tidak pernah aktif.

### Menu dibuang
- Sidebar **Extensions/Plugins** (`src/sidebarApps/index.js`).
- Pengaturan **Plugins**, **Sponsors**, dan **Rate app** serta daftar promosi online (`src/settings/mainSettings.js`).
- Ikon sponsor di sidebar selalu disembunyikan.

### Build
- Plugin Cordova `proot` dan `iap` dikeluarkan dari daftar plugin (`package.json` → `cordova.plugins`). Panduan memakai flag `fdroid` agar `build.sh` tidak menambahkannya lagi.

## Diverifikasi
`npx rspack --mode production` sukses; `npx vitest run` lulus semua.

## Belum disentuh (sengaja)
Kode FTP/SFTP, terminal, LSP, dan halaman about/changelog masih ada di source. Tidak terpanggil otomatis saat start, tapi belum dibuang. Dijadwalkan untuk versi berikutnya agar risiko build tetap kecil.
