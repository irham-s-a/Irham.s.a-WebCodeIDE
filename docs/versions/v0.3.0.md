# v0.3.0 — "Pengembang" (halaman About + logo di dalam app)

Tanggal: 3 November 2026 · versionCode 3

## Pertanyaan awal
Apakah halaman detail pengembang sudah ada? **Belum.** Halaman About bawaan Acode (`src/pages/about/about.js`) hanya memuat data Acode: nama "Acode editor", tautan Foxbiz, situs resmi Acode, serta Twitter, Instagram, GitHub, Telegram, dan Discord milik Acode. Tidak ada nama pengembang fork ini.

## Perubahan
- `src/pages/about/about.js` ditulis ulang. Isi halaman sekarang:
  - Logo dan nama **Irham.s.a WebCode IDE**, versi dan versionCode dari `BuildInfo`.
  - Kartu **Pengembang**: Irham Satria Alfitra · Fullstack Web Developer & AI Learner · Pengembang aplikasi Android dan alat otomasi · Bogor, Indonesia.
  - Kartu **Aplikasi**: info WebView, nama paket, dan kredit "Dibuat dari Acode (lisensi MIT), hak cipta Acode © Foxdebug (Ajit Kumar)".
- Semua tautan dan akun sosial milik Acode dihapus dari halaman About. Pemanggilan iklan `helpers.showAd()` di halaman ini juga dihapus.
- Data pengembang ada di satu objek `DEVELOPER` di bagian atas `about.js`. Kolom `email`, `github`, dan `website` **kosong** secara default dan baris-nya tidak tampil; isi kalau mau menampilkannya (akan membuka browser hanya saat ditekan).
- Logo di dalam app (halaman About dan welcome) diganti dengan logo `</>`: `src/components/logo/logo.png`, `src/pages/about/logo.png`. Cahaya di belakang logo diubah dari biru ke hijau di `src/components/logo/style.scss`.
- Versi dinaikkan ke 0.3.0 (`config.xml`, `package.json`).

## Cara mengubah data pengembang
Edit objek `DEVELOPER` di `src/pages/about/about.js`, lalu build ulang (`docs/BUILD-GUIDE.md`).

## Diverifikasi
`npx rspack --mode production` sukses. Tampilan halaman di perangkat belum dicek.
