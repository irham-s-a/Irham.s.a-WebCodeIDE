# v0.7.0 — Kembali ke atas, play melayang, Beranda permanen

Tanggal: 7 November 2026 · versionCode 10

Dasar: 5 screenshot v0.6.0 dan permintaan pengguna.

## 1. Rel kanan dibatalkan
Rel vertikal di kanan (v0.6.0) membuat editor sempit dan tidak nyaman. Header **kembali ke atas** dengan urutan aslinya:

`☰ (kiri, drawer muncul dari kiri)` · `nama file + path` · `✎ pensil` · `⋮ titik tiga`

Tampilan kapsul melayang dari v0.5.1 tetap dipakai pada header. Editor kembali selebar layar. Menu ⋮ dan ✎ kembali terbuka di posisi aslinya.

## 2. Tombol play/pratinjau mengambang di kanan
- Tombol ▶ **dilepas dari header** dan mengambang di tepi kanan, di atas dok tombol keyboard (sekitar 28 px di atasnya), dengan latar kapsul yang menempel ke tepi kanan. Hanya sebesar ikon play; sisa rel dibuang.
- Elemennya tetap anak header, jadi logika tampil/sembunyinya dari Acode tetap dipakai (hanya untuk berkas yang bisa dijalankan).
- **Tidak muncul di Beranda.** Ada pengaman tambahan: sebelumnya Acode menampilkan ▶ untuk semua tab bila port server ≠ port pratinjau; sekarang Beranda dikecualikan secara eksplisit (`src/main.js`, `onFileUpdate`).

## 3. Drawer: dari kiri, folder di atas
- Drawer kembali muncul dari **kiri** dan gestur geser dari tepi kiri kembali seperti aslinya (perubahan gestur sisi kanan di v0.5.1–v0.6.0 dibatalkan).
- **Penyebab struktur folder di bawah (akhirnya ditemukan):** elemen `resize-bar` (batang untuk menggeser lebar sidebar di tablet) ikut masuk ke alur kolom drawer di ponsel dan memakan sekitar 349 px tinggi, sehingga pohon folder terdorong ke bawah. Sekarang `resize-bar` disembunyikan di ponsel, dan pohon folder mulai tepat di bawah baris ikon tab (Berkas, Cari).
- Warna aktif ikon tab tetap mengikuti aksen tema (perbaikan v0.5.1).

## 4. Default editor
- Ukuran teks bawaan **11px** (sebelumnya 12px).
- **Bungkus baris** (word wrap) aktif bawaan: baris panjang pindah ke bawah, tidak melebihi layar.
- Karena pemasanganmu sudah punya pengaturan tersimpan, kedua nilai ini juga diterapkan **sekali saja** pada pemasangan lama (`wcEditorDefaultsV1` di `src/lib/settings.js`). Sesudah itu, perubahan yang kamu buat di Pengaturan Editor tidak ditimpa lagi.

## 5. Pengaturan tema: tab Terminal dibuang
Halaman Tema masih memuat tab "Terminal" (pemilih tema terminal) padahal terminal sudah dihapus. Tab itu, tiga fungsinya, dan dua import yang hanya dipakainya sudah dibuang (`src/pages/themeSetting/themeSetting.js`).

## 6. Tab Beranda permanen
- Tab Beranda **tidak punya tombol tutup** dan **tidak bisa ditutup dengan cara apa pun**: `remove()` menolak, "Tutup berkas", "Tutup semua tab", "Tutup tab lain", "Tutup tab ke kiri/kanan", dan pintasan tutup tab semuanya melewatinya (`src/lib/editorFile.js`, `src/lib/commands.js`).
- **Selalu dibuka saat aplikasi start**, sebelum berkas dipulihkan (dulu hanya dibuka bila tidak ada berkas). Berkas yang dipulihkan tetap menjadi tab aktif.
- Tidak ada ikon pin/tutup pada tab itu.

## 7. Diverifikasi (aplikasi asli di Chromium, Android ditiru)
- Beranda aktif: tombol ▶ tidak ada, tab Beranda tanpa ikon tutup.
- `index.html` aktif: ▶ terlihat di (309, 642) berukuran 51×50, menempel di tepi kanan layar 360 px; tab `index.html` punya ikon tutup, Beranda tidak.
- Default: ukuran 11px terhitung di editor, `textWrap` aktif, baris panjang terbungkus.
- Mencoba menutup Beranda lewat `remove()`, `remove(..., {ignorePinned})`, `close-tab`, dan `close-all-tabs`: semuanya gagal; setelah `close-all-tabs` hanya Beranda yang tersisa.
- Drawer dengan folder dibuka: pohon folder mulai di y=64, tepat di bawah baris ikon (sebelumnya y=405).
- Build produksi sukses, 927 test lulus, tidak ada variabel tak terdefinisi baru.
Gambar: `docs/preview/v070-*.png` (render browser, bukan screenshot HP; tema terang di gambar karena browser uji tidak meminta tema gelap).

## 8. Belum diverifikasi
- Belum dijalankan di HP.
- Migrasi pengaturan untuk pemasangan lama (11px + bungkus baris) diperiksa lewat pembacaan kode; harness tidak punya berkas pengaturan lama untuk diuji.
- Posisi ▶ (28 px di atas dok) diambil dari posisi pada v0.6.0; sesuaikan angka `bottom` di `src/styles/webcode-ui.scss` bila perlu.

## 9. Cara memasang
Tidak ada perubahan Java atau plugin, jadi **tidak perlu** menghapus `platforms`/`plugins`. Cukup timpa file dari paket pembaruan lalu:

```
npm run build -- paid d fdroid apk
```
