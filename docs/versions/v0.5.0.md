# v0.5.0 — "Rombak" (desain baru, buang terminal/login/plugin)

Tanggal: 4 November 2026 · versionCode 7

Dasar: laporan dan 8 screenshot dari build v0.4.2 di HP.

## 1. Fitur yang dibuang dari antarmuka
| Yang dibuang | Di mana |
|---|---|
| **Login/akun** (ikon avatar dan menu di bawah sidebar, listener login) | `src/components/sidebar/index.js` |
| **Terminal** (menu, baris di Beranda, perintah `new-terminal`, pintasan Ctrl+`, "Pengaturan Terminal", pemulihan sesi terminal saat start) | `menu.hbs`, `commandRegistry.js`, `keyBindings.js`, `commands.js`, `mainSettings.js`, `main.js` |
| **Proses yang berjalan** (daftar proses terminal/layanan) | `menu.hbs`, `commands.js` |
| **Plugin/ekstensi** (baris "Jelajahi Plugin", perintah dan pintasan halaman plugin) | `welcome.js`, `commandRegistry.js`, `keyBindings.js` |
| **Notifikasi sidebar** (lonceng; isinya dari plugin dan akun) | `src/sidebarApps/index.js` |
| **Bantuan** (membuka dokumentasi online Acode) | `menu.hbs` |
| **Tautan sosial** Website, GitHub, Telegram, Discord | Beranda baru |
| **Ikon aplikasi** (pemilih ikon bergaya Acode) dan **Catatan Perubahan** Acode | `mainSettings.js` |
| Teks debug di layar pembuka (versi Android, WebView, bahasa) | `main.js` (hanya muncul jika WebView terlalu lama) |

Fitur editor, pratinjau, Konsol, pemformat, server bahasa (autocomplete dalam aplikasi), tema, cadangan/pulihkan, dan pengelola berkas **tidak dipangkas**.

> **Jujur soal batasnya:** yang dibuang di versi ini adalah jalur antarmuka dan kode yang memanggilnya. Modul native Android untuk terminal (`rk.exec.terminal`), login (`rk.auth`), plugin (`rk.plugin.plugincontext`), FTP, dan SFTP **masih ikut dikompilasi** ke APK, jadi ukuran APK belum mengecil. Menghapusnya di tingkat native menyentuh banyak kelas Java dan manifest, dan saya tidak mau menaruh risiko pada build yang baru berhasil. Itu dijadwalkan sebagai v0.6.0 dan sebaiknya dikerjakan bertahap dengan build di setiap langkah.

## 2. Desain baru (bentuk, tata letak, bahasa visual)
Warna tetap mengikuti tema, jadi semua tema (Hacker, Cyber, Terminal, WebCode Night, dst.) ikut berubah dengan benar.

- **Beranda** ditulis ulang total: kartu hero dengan cahaya aksen dan logo, kisi 2×2 kartu aksi berwarna (Berkas baru, Buka berkas, Buka folder, Berkas terbaru), lalu daftar alat berkartu (Palet Perintah, Ganti tema, Pengaturan, Tentang). Tidak ada lagi daftar teks dengan pintasan keyboard. `welcome.js`, `welcome.scss`.
- **Pengaturan**: bagian-bagian menjadi kartu bersudut membulat, ikon berlencana warna aksen, judul bagian huruf kapital kecil. `src/styles/webcode-ui.scss`.
- **Tab**: berbentuk pil dengan cahaya pada tab aktif (bukan lagi tab persegi dengan garis atas).
- **Header**: transparan dengan garis cahaya gradasi di bawahnya.
- **Sidebar**: sudut kanan membulat 28 px, rel ikon berbentuk kapsul melayang.
- **Menu konteks, dialog, tombol, input**: sudut membulat, bayangan lembut.
- **Dok tombol keyboard** di bawah: sudut atas membulat.
- **Tema bawaan baru "WebCode Night"** (navy gelap, aksen zamrud dan cyan) untuk pemasangan baru; perangkat berlatar terang memakai "Paper". Pemasangan lama tidak diubah.
- **Layar pembuka**: logo animasi sekarang hijau-cyan (`www/logo.svg`) dan hanya menampilkan "Irham.s.a WebCode IDE vX.Y.Z".
- Glyph ikon "acode" (tab Beranda) diganti logo WebCode lewat CSS mask.

Gambar rancangan ada di `docs/preview/` (beranda, pengaturan, sidebar dan tab). **Itu render rancangan dengan CSS asli aplikasi di browser, bukan screenshot dari HP.** Tampilan nyata di HP-mu mungkin sedikit berbeda.

## 3. Teks yang menyebut Acode
Diganti: judul header awal, deskripsi skala teks, nama berkas cadangan (`WebCode_backup_...`), nama berkas log, contoh kode di pratinjau tema, pesan error WebView di `www/index.html`, judul halaman. Yang tersisa hanya kredit lisensi di halaman Tentang (wajib dalam lisensi MIT) dan nama folder/berkas internal yang tidak terlihat pengguna.

## 4. Diverifikasi
- `npx rspack --mode production` sukses; `npx vitest run`: 96 file / 927 test lulus; lint tidak menemukan variabel tak terdefinisi baru dibanding file aslinya.
- Tiga rancangan di atas dirender di Chromium dengan CSS asli hasil build.

## 5. Belum diverifikasi
Seluruh perubahan ini belum dijalankan di HP. Yang paling perlu dicek: (a) tombol-tombol di Beranda (Berkas baru, Buka berkas, Buka folder, Terbaru, Palet Perintah, Ganti tema, Pengaturan, Tentang) benar-benar membuka yang dimaksud, (b) menu titik tiga tidak lagi memuat Terminal, Proses yang berjalan, dan Bantuan, (c) bagian bawah sidebar tidak lagi memuat ikon akun, (d) animasi loading hijau.

## Cara memasang
Timpa file dari paket pembaruan, lalu build ulang seperti biasa. Folder `platforms` **tidak perlu** dihapus kali ini, karena tidak ada perubahan pada plugin Java.
