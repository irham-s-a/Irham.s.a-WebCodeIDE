# v0.5.1 — Perbaikan Beranda hilang + warna aktif + tata letak baru

Tanggal: 5 November 2026 · versionCode 8

## 1. Bug: halaman Beranda tidak muncul, error sekilas (BUG DARI SAYA)
**Gejala (laporan):** setelah v0.5.0, Beranda tidak tampil dan muncul peringatan error sekilas saat aplikasi dibuka.

**Penyebab:** di v0.5.0 saya membuang panel "Notifikasi" (ikon lonceng) dari sidebar, tanpa memeriksa siapa yang masih memintanya. `notificationManager.init()` (dipanggil tepat sebelum Beranda dibuka) memanggil `sidebarApps.get("notification")`, dan `get()` langsung membaca `app.container` dari hasil pencarian yang kini kosong. Hasilnya `TypeError`, startup berhenti sebelum `openWelcomeTab()`, dan Beranda tidak pernah dibuat. Ini bukan penghapusan yang disengaja.

**Perbaikan:** `src/sidebarApps/index.js`: `get()` sekarang mengembalikan `undefined` (`app?.container`) untuk panel yang tidak ada. Pemakai lain (`notificationManager`) memang sudah memakai `?.`.

**Pembuktian (aplikasi asli dijalankan di Chromium dengan Cordova tiruan, penanda log dipasang sementara lalu dicabut):**
- Tanpa perbaikan: log berhenti setelah "before notificationManager.init", tidak ada "after", dan jumlah berkas tetap 0 → Beranda tidak dibuka.
- Dengan perbaikan: startup lanjut sampai Beranda terbuka (jumlah berkas 1) dan tampilannya sesuai rancangan.

## 2. Warna aktif/hover yang saling menimpa
Dua penyebab terpisah:
1. **Tema-tema baru buatan saya:** `--active-icon-color` dipakai banyak panel (simbol, referensi, dialog LSP) sebagai warna **latar** item aktif/hover. Di v0.2.0 saya mengisinya warna aksen penuh, padahal teks/ikon di atasnya juga berwarna aksen, jadi menyatu. Sekarang nilainya aksen transparan 20% (`src/theme/preInstalled.js`).
2. **Drawer sidebar:** latar aktif/hover memakai overlay putih tetap `rgba(255,255,255,…)`, tidak peduli tema (nyaris tak terlihat di tema terang). Sekarang mengikuti aksen tema: latar aksen transparan, ikon berwarna aksen penuh, dan garis tepi tipis. Diperiksa pada tema Hacker, Paper (terang), dan Cyberpunk Edge (aksen kuning); lihat `docs/preview/app-drawer-aktif-terang-vs-gelap.png`.

## 3. Tata letak: tidak lagi seperti Acode
| Komponen | Acode | WebCode IDE |
|---|---|---|
| Rel ikon drawer | kolom vertikal di kiri | **dok kapsul horizontal di dasar drawer**, indikator aktif berupa titik di bawah ikon |
| Tab berkas | di bawah header | **di bawah layar, di atas tombol keyboard**, berbentuk pil |
| Header | batang penuh di atas | **kapsul melayang** (bentuk ini digambar dengan lapisan terpisah, jadi ukuran tata letak tidak berubah) |
| Tombol keyboard | grid tombol datar | tombol berbentuk chip dengan jarak |
| Drawer | persegi | sudut kanan membulat 30 px |

Tab di bawah adalah pengaturan bawaan untuk pemasangan baru. **Untuk pemasangan lama**, ada migrasi sekali jalan (`wcLayoutV1` di `src/lib/settings.js`): tab dipindah dari header ke bawah satu kali saja; pilihan yang kamu ubah sesudahnya tidak ditimpa lagi (Pengaturan → Pengaturan Aplikasi → posisi daftar berkas).
